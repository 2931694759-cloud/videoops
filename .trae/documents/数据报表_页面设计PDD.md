# 数据报表｜页面设计说明（Desktop-first）
> 目标：在**不改变现有系统外壳**的前提下，补齐内容区的信息结构与交互规范（切换/弹窗/浮层/toast）。

## 1) Layout
- **整体布局**：沿用现有“顶部 Header + 左侧 Sidebar + 内容区 Content”的系统壳结构；本页仅实现 Content 区。
- **内容区栅格**：推荐 CSS Grid（12 列）+ 局部 Flex。
  - 顶部筛选区：一行自适应（左：筛选控件；右：口径说明/导出）。
  - 指标卡片：4~5 张卡片等宽分布，超出换行。
  - 图表区：上图下表（纵向堆叠），图表高度固定区间（例如 320~420px），随窗口宽度自适应。
- **响应策略**：桌面优先；当宽度 < 1200px 时卡片换行；表格保持横向滚动而非挤压列宽。

## 2) Meta Information
- Title：数据报表
- Description：按时间与维度查看核心指标趋势与明细。
- Open Graph：沿用现有系统默认配置（不额外修改）。

## 3) Global Styles（沿用现有系统，仅补充约束）
- 主题色/字体/圆角/阴影：全部沿用现有 Design Token。
- 页面背景：沿用内容区默认背景；卡片使用系统标准卡片样式。
- 按钮：主按钮用于“应用”；次按钮用于“重置/取消”；危险按钮不使用。
- 链接：表格行内“查看详情”使用系统链接样式。
- 动效：统一使用 150~200ms ease-out 过渡（浮层/弹窗出现、Tab 切换）。

## 4) Page Structure（内容区）
自上而下分 5 个区块：
1. 面包屑/标题区（若系统壳已提供标题栏，则复用，不重复渲染）
2. 筛选与操作区
3. 指标总览卡片区
4. 图表区（含指标切换）
5. 明细表区（含分页、排序、下钻入口）

## 5) Sections & Components

### 5.1 筛选与操作区（顶部）
- **组件**：
  - 时间范围：快捷选项（近7天/近30天）+ 自定义日期范围选择器。
  - 粒度切换：Segmented（日/周/月）。
  - 维度选择：Select（内容/账号/渠道/地区…以现有为准）。
  - 对比方式：Radio（环比/同比，默认环比）。
  - 操作按钮：主按钮“应用”，次按钮“重置”。
  - 右侧操作：链接/按钮“数据口径说明”、按钮“导出”。
- **交互（切换）**：
  - 修改任一筛选项仅标记为“已更改未应用”状态（按钮区出现轻提示或按钮高亮），点击“应用”才请求刷新。
  - 粒度与时间范围联动：当选择过短时间范围导致粒度不可用时，粒度置灰并提示原因（tooltip 浮层）。
- **状态**：加载中时“应用”置为 loading，避免重复提交。

### 5.2 数据口径说明（浮层/抽屉）
- **触发**：点击“数据口径说明”。
- **形态**：右侧抽屉（优先）或 Popover 浮层（内容较长不建议）。
- **内容结构**：通用口径（时区/延迟/粒度）+ 指标定义 + 维度解释 + 异常处理规则。
- **交互**：提供“复制口径”按钮；复制成功 toast。

### 5.3 指标总览卡片区
- **布局**：4~5 卡片栅格；每卡片包含：指标名、当前值、对比值（↑↓ + 百分比/差值）、对比周期标签。
- **交互**：
  - hover 卡片显示信息 icon tooltip（浮层）解释指标简述。
  - 点击卡片可将该指标设为图表主指标（与图表区联动）。

### 5.4 图表区（含指标切换）
- **结构**：
  - 顶部：主指标选择 Tabs/Dropdown（与卡片一致）。
  - 主体：趋势图（折线/柱状，按现有图表规范）。
- **交互（浮层）**：
  - hover 数据点显示 tooltip：日期 + 主指标值 + 其他关键指标值（精简展示，最多 4 行）。
  - 空态：当 trend 全为空/全 0，根据产品约定展示“暂无数据”。

### 5.5 明细表区
- **表头**：随维度变化（例如“内容维度”显示内容名称/ID；其余列为指标列）。
- **排序**：默认按当前主指标降序；点击列头切换升/降序；排序变化立即请求。
- **分页**：标准分页组件，支持 pageSize（若系统已有全局约定则沿用）。
- **行内操作**：
  - “查看详情”链接
  - 或整行可点击（需与现有表格可点击规范一致）

### 5.6 下钻详情（弹窗）
- **触发**：点击“查看详情”或行。
- **形态**：Modal 弹窗（宽 900~1100px，桌面优先）。
- **内容**：
  - 顶部：对象名称 + ID（可复制）
  - 子 Tab（切换）：概览 / 趋势 / 明细（最少保留“概览、趋势”）
  - 概览：与指标卡片同口径
  - 趋势：与主图同组件复用
- **交互**：关闭弹窗后，主页面筛选不变、滚动位置尽量保留。

### 5.7 Toast 与异常反馈规范
- **成功**：复制口径、导出任务创建成功 → toast（2~3s 自动消失）。
- **失败**：接口 500/网络异常 → toast + 页面区域级错误态（提供“重试”按钮）。
- **权限**：403 → toast“无权限查看数据报表”，并提供“返回上一页”。
- **导出确认弹窗**：点击“导出”先弹确认 Modal：展示筛选条件摘要、预计条数（若后端不支持预估则不展示），确认后触发导出并 toast。

## 6) 数据展示格式（口径一致性落到 UI）
- 数值格式：
  - 播放量/互动量：整数，千分位
  - 观看时长：默认展示为“hh:mm:ss”（同时保留 tooltip 显示秒）
  - 比率：百分比，保留 2 位小数；null 显示“—”
- 时间标签：与粒度一致（日/周/月），并在图表 tooltip 中展示完整范围（周粒度显示周起止）。
